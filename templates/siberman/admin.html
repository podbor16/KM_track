Расписание этапов

Подставлено из сохранённого старта года — меняйте только если старт реально сдвинулся (экстренная правка). Сохраняется вместе с загрузкой файла ниже, отдельной кнопки не требует.

Вело День 2 / Бег управляют тем, какой этап на публичной странице считается "текущим" (пульсирующая точка на табе, автоскролл) — Вело День 1 не задаётся отдельно: он становится активным сразу по факту первого финиша заплыва, а не по расписанию. Пустое поле — переключение по времени для этого этапа отключено (страница останется на предыдущем).

Публичный год

Какой год показывается на ПУБЛИЧНОЙ странице результатов (/) — независимо от того, какой год вы сейчас загружаете выше. Загрузка нового года не переключает публичную сама по себе, пока это явно не сделано тут.

Copernico live (бег)

Включает live-опрос Copernico для бегового этапа — без SSH, кнопка запускает/останавливает опрос напрямую. Выключено по умолчанию.

Live-синхронизация из Google Таблицы

Альтернатива ручной загрузке Excel-файла ниже — таблица должна быть открыта по ссылке («Все, у кого есть ссылка» → «Читатель»). Кнопка запускает/останавливает опрос напрямую, без SSH — изменения подтягиваются автоматически, пока включено. Не запускайте одновременно обычную загрузку Excel для этого же года — она перезапишет всех участников заново.
