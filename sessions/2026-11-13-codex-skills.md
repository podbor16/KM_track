# Скиллы Codex: CI, субагенты и Q&A

Дата: 2026-11-13

## Что сделано

- Установлен скилл `gh-fix-ci` и его read-only скрипт проверки PR checks из каталога OpenAI Skills (Apache-2.0). Добавлено проектное дополнение для анализа workflow runs деплоя по run ID; скрипт при этом остаётся предназначенным для PR checks. [Исходник OpenAI](https://github.com/openai/skills/tree/main/skills/.curated/gh-fix-ci)
- Добавлен `delegation-policy`: разбиение только независимых направлений, выбор доступной модели по сложности, запрет конфликтующего параллельного редактирования и сведение доказательств главным агентом.
- Добавлен `qa-mode`: Q&A по запросу пользователя, один существенный вопрос за раз, без повторных подтверждений и без остановки на выводимых из контекста деталях.
- В `AGENTS.md` добавлены правила маршрутизации задач к этим скиллам.
- По правилу проекта после существенной работы делаются необходимые коммиты и push, если нужна синхронизация с `origin` или запуск CI/CD. Перед commit проверяется staged diff; перед push — точный outgoing диапазон коммитов на секреты, учётные данные и персональные данные. В индекс попадают только файлы текущей задачи. Push, вызывающий production deploy, требует проверки разрешения и явного сообщения пользователю.

## Ограничения и проверка

- Изменения находятся локально в репозитории; страницы Tilda и production не затрагивались.
- Внешнее хранилище Obsidian доступно только для чтения в этой сессии. Эту запись нужно перенести в `sessions/` Obsidian и добавить ссылку в `00-home/index.md` при наличии доступа на запись.
- Скилл `gh-fix-ci` охватывает GitHub Actions. Встроенный скрипт работает с PR checks; проектное дополнение описывает ручной разбор run ID, включая workflow деплоя. Другие CI-провайдеры не охвачены.
- Поведенческую проверку скиллов и запуск CI не выполнял.
- Obsidian остаётся доступен только для чтения; эту заметку нужно перенести туда и добавить ссылку в индекс при наличии доступа на запись.
