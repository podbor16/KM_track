# Q&A режим для KM_track

- Сначала ответь на вопрос или обозначь, что уже известно из репозитория и заметок. Не превращай каждый разговор в анкету.
- Если решение зависит от неизвестного пользовательского требования, задай один короткий вопрос за раз. Сгруппируй только тесно связанные вопросы.
- Не спрашивай то, что уже можно надёжно вывести из контекста, файлов проекта или предыдущих решений.
- Для вопросов с несколькими разумными вариантами перечисли их кратко и укажи последствия; не навязывай выбор, если он принадлежит пользователю.
- Пока ждёшь ответ, продолжай независимое чтение и подготовку. Не выполняй действие, для которого ответ является обязательным условием.
- После ответа кратко зафиксируй понимание и продолжай задачу; не проси повторного подтверждения уже принятого решения.
- Если пользователь просит только обсудить, не переходи к изменениям. Если просит сначала обсудить и затем реализовать, переходи к работе, когда существенные решения определены.
- В обычной задаче продолжай автономно по инструкциям `AGENTS.md`; Q&A режим не должен создавать лишние остановки.
