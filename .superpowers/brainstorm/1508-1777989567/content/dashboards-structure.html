Структура дашбордов бизнес-аналитики

4 тематических раздела — каждый со своим набором чартов и фильтрами

🏅
Дашборд судьи
Результаты мероприятий
  • Итоговая таблица результатов
  • Разбивка по полу / возрастным категориям
  • Финиш / DNF / DNS по мероприятию
  • Средний темп по категориям
  • Прохождение КТ (воронка дропаутов)
✅ Данные: таблица results в текущей БД
📈
Маркетинг
Регистрации, выручка, клиенты
  • Выручка за период / по мероприятию
  • Средний чек на участника
  • Динамика регистраций по времени
  • Льготники / полная цена
  • Выручка: слоты vs доп. товары
⚠️ Данные: нужна таблица регистраций/платежей
🗺️
Геоаналитика
Откуда приезжают участники
  • Карта участников по регионам/городам
  • Топ городов (динамика по годам)
  • Доля местных vs иногородних
  • Новые города (впервые участвуют)
✅ Данные: поле city в таблице заявок
👥
Клиентская база
Новые и повторные участники
  • Новые участники (по году, мероприятию)
  • Повторные участники (retention)
  • LTV клиента по годам
  • Переход между дистанциями
⚡ Данные: client_id в results — частично готово
⚠️ Пробел в данных: финансовая информация
Текущая БД содержит только результаты забегов. Для маркетинг-дашборда (выручка, средний чек, льготники) нужна таблица регистраций/платежей — из системы регистрации участников (например, Copernico, SportSoft, или 1С). Нужно обсудить откуда берутся эти данные.
