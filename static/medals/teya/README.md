# Сертификаты Тёи

В предварительной сборке пять временных рамок. Перед передачей участникам потребуется подключить финальные изображения.

## Если у вас есть доступ к хостингу

1. Распакуйте ZIP и через файловый менеджер хостинга загрузите папку `teya` целиком в каталог, доступный с сайта. Сохраните структуру папок. В папке `teya` должны находиться `index.html`, `certificate.config.json`, файлы JavaScript и CSS и каталог `template`.
2. Откройте адрес папки по HTTPS, например `https://example.org/teya/`. Если хостинг не открывает `index.html` автоматически, используйте `https://example.org/teya/index.html`. Для работы достаточно обычного хостинга статических файлов.
3. Добавьте этот адрес на сайт кнопкой «Сделать сертификат» или вставьте генератор в страницу по инструкции ниже.

## Если у вас есть доступ только к редактору WordPress

1. Получите рабочий HTTPS-адрес генератора у того, кто разместил файлы. Если готового адреса ещё нет, попросите владельца хостинга выполнить шаги выше.
2. Откройте файл `wordpress-embed.html` в текстовом редакторе и замените `https://example.org/teya/` в обоих местах на рабочий адрес.
3. Скопируйте содержимое файла в виджет **HTML** в Elementor или в блок **Произвольный HTML** в редакторе WordPress. Сохраните страницу и проверьте предпросмотр. Под генератором будет ссылка для открытия на отдельной странице.
4. Если редактор удаляет вставку или хостинг блокирует показ страницы внутри iframe, добавьте обычную кнопку WordPress «Сделать сертификат» и укажите тот же адрес.

## Проверка перед открытием доступа участникам

- Откройте прямой адрес и страницу WordPress после сохранения. На компьютере и телефоне выберите фото, смените рамку, скачайте и откройте готовое изображение. На iPhone отдельно проверьте сохранение через меню «Фото» или загрузку по прямой ссылке.
- Проверьте все пять финальных рамок, включая обрезку портретного и горизонтального фото. Сверьте скачанный файл с предпросмотром.

Для локального просмотра запустите в папке `teya` команду `python -m http.server 8000` и откройте `http://localhost:8000/`. Страница загружает конфигурацию и модули через веб-сервер.

Финальные рамки нужны в виде PNG размером 1080 × 1920 с прозрачной областью для фотографии. Фото рисуется под рамкой. При подключении файлов обновите адреса `src`, `thumbnail` и резервное поле `overlay` в `certificate.config.json`. Проверьте, что подсказка `placeholder` находится в области для фото.
