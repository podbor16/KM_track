# Сертификаты Тёи

Генератор включает пять оформлений. Участник выбирает рамку, добавляет фото и сохраняет сертификат в JPG размером 1080 × 1528. Фото обрабатывается в браузере.

## Размещение страницы

1. Распакуйте ZIP. Загрузите папку `certificates` целиком в корневой каталог сайта. Файл `index.html` должен находиться прямо в `certificates`, рядом с `certificate.config.json`, файлами JavaScript и CSS и папкой `template`.
2. После загрузки откройте `https://xn--19-mlc5c8c.xn--p1ai/certificates/`. Если хостинг не открывает `index.html` автоматически, используйте `https://xn--19-mlc5c8c.xn--p1ai/certificates/index.html`.
3. Передайте рабочий HTTPS-адрес редактору сайта. Этот адрес он укажет в своей кнопке на сайте.

## Проверка перед открытием доступа участникам

- Перейдите на страницу по кнопке на сайте. На компьютере и телефоне выберите фото, смените рамку, скачайте и откройте готовое изображение. На iPhone проверьте сохранение в приложение «Фото».
- Проверьте все пять финальных рамок, включая обрезку портретного и горизонтального фото. Сверьте скачанный файл с предпросмотром.

Для локального просмотра запустите в распакованной папке `certificates` команду `python -m http.server 8000` и откройте `http://localhost:8000/`. Страница загружает конфигурацию и модули через веб-сервер.

При замене оформления используйте PNG размером 1080 × 1528 с прозрачной областью для фотографии. Фото рисуется под рамкой. Если меняете имена файлов, обновите адреса `src`, `thumbnail` и резервное поле `overlay` в `certificate.config.json`.
