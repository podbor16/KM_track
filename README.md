# KM_track

**Платформа для организаторов беговых и триатлонных соревнований** — живое отслеживание участников на карте во время гонки и подробная аналитика результатов после финиша.

Дипломный проект, но не учебный макет: система работает на реальных соревнованиях и обслуживает живых зрителей, участников и организаторов во время гонки.

## Что делает система

**Во время гонки:**
- Показывает всех участников на карте в реальном времени — где кто находится прямо сейчас
- Считает текущую скорость и прогнозирует, когда участник дойдёт до следующей контрольной точки
- Поиск конкретного участника по имени или номеру

**После финиша (и по ходу многодневных гонок):**
- Таблицы результатов с местами — в абсолютном зачёте, по полу, по возрастным категориям
- Персональная карточка участника: время на каждом отрезке, отставание от лидера, история прохождения
- Графики темпа/скорости и позиции в гонке на протяжении дистанции
- Отдельная логика для командных/эстафетных форматов

**Для организаторов:**
- Админ-панель для загрузки результатов и управления событием
- Переключение между несколькими одновременно проводимыми гонками

Система уже принимала данные реальных соревнований — в том числе многодневного триатлона Siberman (515 км: заплыв, два дня велоэтапа, марафон) и женского забега «Семёрка».

## Технологии

Backend — Python (FastAPI), MySQL. Frontend — JavaScript, Leaflet.js (карты), Chart.js (графики), без тяжёлых фреймворков. Обновления на карте — через Server-Sent Events (SSE), без перезагрузки страницы. Разворачивается на собственном сервере (VPS) с автоматическим деплоем при каждом обновлении кода.
