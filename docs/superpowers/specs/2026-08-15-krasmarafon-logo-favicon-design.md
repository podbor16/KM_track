# Логотип в навбаре + favicon для Красмарафона — дизайн

## Контекст

Задача из бэклога (зафиксирована 2026-08-15, после завершения программы редизайна): заменить логотип в хэдере, сделать favicon, проверить корпоративный шрифт на всех страницах. Эта спека закрывает первые два пункта (логотип + favicon) — оба оказались дизайн-решениями с реальными компромиссами, разобраны через brainstorming с visual companion. Проверка шрифта — отдельный аудит без дизайн-решений, не в этой спеке.

Пользователь дал 3 исходных файла:
- `static/images/krasmarafon/КМ.png` (1549×634, RGBA с прозрачностью) — полный лого-локап: графический знак «KM» (тройной штрих + волна) сверху + текст «КРАСМАРАФОН» снизу. Знак и текст разделены чистым прозрачным зазором по вертикали (строки 454-551 из 634 полностью пустые) — знак вырезается без артефактов.
- `static/images/krasmarafon/Krasmarafon_широкий.png` (883×50) — оказался при проверке побайтово тем же текстовым вариантом, что уже используется как `static/images/krasmarafon-logo.png`. Не используется дальше, отдельного значения не несёт.
- `static/images/krasmarafon/KM_pink.jpg` (1000×1000, RGB) — готовая квадратная app-icon-подобная иконка: белый знак на фирменном розовом фоне (`≈ --km-primary`). Найдена пользователем позже, по ходу брейнсторминга favicon — не требует кропа/паддинга, уже квадрат.

## Текущее состояние (до правки)

- Единственное живое место логотипа в вёрстке — `templates/krasmarafon/header.html` (общий инклюд на 7 страницах: admin/athlete-profile/history/race-analysis/results/start_list/tracker), класс `.navbar-logo-img` в `static/css/navigation.css`: `height: 26px; width: auto` (на мобилке `max-width: 140px`). Показывает текстовый `krasmarafon-logo.png` (883×50, соотношение 17.66:1).
- `templates/krasmarafon/krasmarafon_header.html` (официальный хэдер krasmarafon.ru с тем же лого) — мёртвая разметка, нигде не заинклюжена (убрана 2026-08-12). Не трогаем.
- `templates/krasmarafon/login.html` — свой изолированный тёмный топбар (`.km-topbar`, не использует `km-design-tokens.css` вовсе), сейчас текстовый мини-логотип «КМ»+«ТРЕК» (другое, отдельное название, не «Красмарафон»), ссылка на `/`.
- Favicon (`<link rel="icon">`) есть только на `admin.html` и `tracker.html`, оба указывают на тот же плоский текстовый PNG (883:50) — в квадратном слоте favicon это нечитаемая полоса. На `athlete-profile.html`/`history.html`/`race-analysis.html`/`results.html`/`start_list.html`/`login.html` favicon нет вовсе.
- Для сравнения: у Siberman (`templates/siberman/*.html`) уже есть нормальный набор — `favicon.ico` (`sizes="any"`) + `favicon-32.png` (`type="image/png" sizes="32x32"`) + `apple-touch-icon.png` (180×180) + `favicon-512.png` (используется как `og:image` на `results.html`).

## Дизайн-решения (брейншторминг с visual companion)

Сравнивались реальные файлы при реальных CSS-размерах (навбар #222222, высота 26px для лого) — не абстрактные мокапы.

### 1. Логотип в навбаре → только знак (без текста)

Проверено вживую: полный локап (`КМ.png`) при текущей высоте навбара 26px даёт нечитаемый текст (текстовая часть — маленькая доля общей высоты картинки). Расти навбару пользователь не захотел — **выбран знак без текста**, вырезанный из верхней части `КМ.png` (строки 0-453, вся ширина 0-1548, соотношение 3.41:1). Высота навбара и `.navbar-logo-img` в CSS **не меняются** — тот же `height: 26px`, при новом соотношении сторон рендерится ~89px шириной (было ~459px) — с запасом укладывается и в мобильный `max-width: 140px`, эту правку в CSS менять не нужно.

### 2. Favicon → готовая розовая иконка (KM_pink.jpg)

Сравнивались: (а) знак с прозрачным паддингом до квадрата — на 16px превращается в тонкую едва различимую полоску; (б) квадратный кроп левого фрагмента знака — крупнее, но это уже не весь знак, только фрагмент; (в) `KM_pink.jpg` — готовый непрозрачный квадрат, при уменьшении до 16-32px читается чище всех вариантов (проверено в мокапе вкладки браузера, светлая и тёмная тема). **Выбран вариант (в)**.

Набор файлов — по тому же контракту, что уже у Siberman (`static/images/siberman/*`), просто с источником `KM_pink.jpg` вместо соответствующего siberman-исходника:
- `favicon.ico` — multi-size ICO (16/32/48), `<link rel="icon" href="..." sizes="any">`
- `favicon-32.png` — 32×32, `<link rel="icon" type="image/png" href="..." sizes="32x32">`
- `apple-touch-icon.png` — 180×180, `<link rel="apple-touch-icon" href="...">`
- `favicon-512.png` — 512×512, про запас под `og:image` (как на `siberman/results.html`) — сама og:image-разметка НЕ добавляется в этой задаче (не просили), только файл генерируется заодно, раз источник уже под рукой

Все 4 файла генерируются из `KM_pink.jpg` простым ресайзом (источник уже квадратный, без кропа/паддинга).

### 3. login.html → тот же знак, что в навбаре

Сравнивались: (а) тот же знак-без-текста, что в навбаре (единообразие) vs (б) полный локап покрупнее (в топбаре логина места больше — нет соседних пунктов меню). **Выбран вариант (а)** — единый знак как единственная узнаваемая точка бренда по всему сайту, а не третий отдельный вариант лого. Заменяется `<a href="/" class="logo-text">КМ<span>ТРЕК</span></a>` на `<a href="/" class="logo-text"><img src="..." style="height:26px;width:auto;display:block;" alt="Красмарафон"></a>` — тот же `height: 26px`, что и в навбаре (визуальная консистентность), топбар логина сам по себе достаточно похож по масштабу (~42px высотой), явно перестраивать `.km-topbar` не нужно.

## Затрагиваемые страницы (favicon-теги + логотип)

Логотип (`header.html`) — 1 правка покрывает все 7 страниц через общий инклюд: admin/athlete-profile/history/race-analysis/results/start_list/tracker.

Favicon-теги — добавляются в `<head>` явно на каждой из публичных krasmarafon-страниц (в проекте нет общего `<head>`-инклюда, у каждого шаблона свой `<head>`): `athlete-profile.html`, `history.html`, `race-analysis.html`, `results.html`, `start_list.html`, `login.html`. На `admin.html`/`tracker.html` уже есть `<link rel="icon">` — их одну строку меняем на новый набор из 3 тегов, а не просто добавляем к старой.

`diploma.html` — отдельная полноэкранная страница без общего хэдера/футера (см. её докстринг), favicon туда тоже добавляется для консистентности (публичная страница, может быть открыта напрямую по ссылке).

## Не в объёме этой спеки

- Проверка использования корпоративного шрифта на всех страницах — отдельный аудит без дизайн-решений, будет сделан сразу после этой задачи, без brainstorming
- `krasmarafon_header.html` (мёртвая разметка) — не трогаем
- `og:image`-разметка (сам мета-тег) — файл `favicon-512.png` создаётся про запас, но тег `<meta property="og:image">` не добавляется, этого не просили
- Текст в футере (`krasmarafon_footer.html`, «ООО «КРАСМАРАФОН»») — текстовый, не про графический логотип, не трогаем
