# Редизайн history.html — дизайн

## Контекст

Пятый под-проект программы «Редизайн всего сайта Красмарафона, кроме
карточки над трекером и самого трекера» (см. `текущие приоритеты.md` →
КРАСМАРАФОН → Подготовка к Жаре, п.1). `results.html`, `start_list.html`,
`race-analysis.html` и `athlete-profile.html` уже задеплоены в едином
«km-*» дизайн-языке. Эта спека закрывает `history.html` — самую маленькую
и простую страницу программы (75 строк HTML, 247 строк CSS): заголовок +
вступительный текст + 2 карточки-выбора рядом (поиск спортсмена /
переход к анализу забегов).

Направление выбрано текстовым брейнштормингом (без visual companion —
страница маленькая, оба решения напрямую переиспользуют уже одобренные
паттерны с прошлых 4 страниц, нового визуального сравнения не
требовалось).

## Изменения

### 1. Карточки-выбора (`.search-option`)

Сейчас: `border: 2px solid var(--km-primary, #EE2D62)` (розовая рамка
всегда включена), `:hover` — `transform: translateY(-4px)` + усиленная
тень + рамка темнеет до `#d41f52`.

Новый вид (тот же язык, что `race-card`/`extended-stat-item` на
`athlete-profile.html`): нейтральная тонкая рамка
`1px solid var(--km-border-light, #e0e0e0)` по умолчанию, без цветного
акцента. `:hover` — убрать `transform`, оставить только усиление тени
(`var(--km-shadow-hover, 0 4px 12px rgba(0,0,0,0.15))`), без изменения
цвета рамки.

**Уточнено с пользователем:** несмотря на то, что эти 2 карточки —
не карточки с данными (как `race-card`), а главные точки входа в два
сценария страницы, выбрана та же нейтральная рамка, что и везде на
сайте — ради консистентности, не смотря на иную роль элемента.

### 2. CTA-кнопка «Перейти к анализу забегов» (`.race-analysis-btn`)

Сейчас: `background: linear-gradient(135deg, var(--km-primary), #d41f52)`,
`:hover` — смена на другой градиент + `transform: translateY(-2px)` +
усиленная тень.

Новый вид (по образцу `.km-btn-export`, `static/css/analytics.css:103-127`
— общий флэт-стиль CTA-кнопки, уже используется для «Скачать PDF» на
`results.html`/`start_list.html`): плоская заливка `background:
var(--km-primary)`, `:hover` — `background: #d4254f` +
`transform: translateY(-1px)` (лёгкий подъём — кнопочная, а не
карточная семантика, тот же уровень, что у `.km-btn-export:hover`) +
усиленная тень. Только цвет заливки/hover меняются — размер, padding,
позиция (крупная, по центру, внизу карточки) не меняются, это
единственный CTA на странице и должен оставаться заметным.

### 3. Не в объёме этой спеки

- `.container`, заголовок `<h1>`, `.intro-section` — уже в едином стиле
  сайта (km-shadow/km-radius-card/km-font-brand), не меняются
- Поле поиска (`.athlete-search-input`) и автодополнение
  (`.autocomplete-results`/`.autocomplete-item`) — уже плоские, белый
  фон, обычная рамка, не нуждаются в изменениях
- JS-логика поиска (`static/js/history.js`) — не меняется, эта задача
  чисто визуальная
- Остальные страницы программы редизайна (`business-analytics.html`,
  `admin.html`) — отдельные будущие под-проекты

## Тестирование

- Полный прогон существующего Python test suite (страница не завязана
  на backend-логику, но регрессия по общим CSS-файлам должна быть
  исключена) — `conda run -n base python -m pytest tests/unit/ -q`
- У этой страницы нет собственной JS-логики, требующей нового
  postoянного теста (в отличие от pill-переключателей на прошлых
  страницах) — изменения чисто CSS, автоматического теста не требуется
- Визуальная проверка в браузере (agent-browser) — десктоп и мобильная
  ширина:
  - Карточки-выбора — тонкая нейтральная рамка, hover без сдвига,
    только тень усиливается
  - CTA-кнопка — плоская заливка без градиента, лёгкий подъём на hover
  - Мобильная ширина — 2 карточки складываются в 1 колонку (уже
    работает, не трогается), ничего не переполняет экран горизонтально
