# Личный кабинет Б3: «Найти себя» и обращения — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** поиск своей карточки по ФИ+ДР+номеру с заявлением «Это я» и очередь обращений (спор, «не мой забег», «не могу найти себя») с решениями в админке и письмами.

**Architecture:** сервисы `athlete_find.py` (поиск, лимит, подписанный токен) и `athlete_requests.py` (обращения, решения, письма) по образцу `athlete_claims.py`/`athlete_reps.py`; заявление после поиска — общий код `athlete_claims._claim` с флагом «без п.1»; вкладка «Обращения» в админке.

**Tech Stack:** FastAPI, Jinja2, mysql-connector (пул autocommit=True), pytest, JS админки.

**Спецификация (читать целиком):** `docs/superpowers/specs/2026-11-04-athlete-b3-design.md`; контекст — specs Б1 и Б2.
