## Задача: Страница аналитики финишного времени участников КМ

### Цель
Добавить в приложение KM_track страницу с топ-10 участников по времени финиша для каждой дистанции (10 км, 21 км, 42 км).

### Требования
- Flask endpoint GET /analytics/top?distance=10km
- SQL-запрос с сортировкой по finish_time ASC, группировка по distance
- Jinja2-шаблон с таблицей результатов
- CSS-стилизация таблицы (адаптивная)
- Интеграционные тесты с реальными данными из БД

### Технический стек
Python, Flask, SQLAlchemy, Jinja2, HTML/CSS, pytest
